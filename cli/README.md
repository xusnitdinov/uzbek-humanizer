# uzbek-humanizer-cli

Installer for the [uzbek-humanizer](https://github.com/xusnitdinov/uzbek-humanizer) Agent Skill.

```bash
npm i -g uzbek-humanizer-cli
uzhumanizer init --ai cursor
uzhumanizer init --ai all --global
uzhumanizer uninstall --ai cursor
```

Bundles the full skill payload. Prefer this registry (npmjs) for normal installs.

GitHub Packages mirror (optional, needs `read:packages` token):

```bash
npm i -g @xusnitdinov/uzbek-humanizer-cli --registry=https://npm.pkg.github.com
```
