# Phraseology rules

## Policy

1. Never invent idioms or maqollar
2. Remap only when sure
3. Otherwise paraphrase plainly
4. Watch ambiguity (`koʻz yummoq` = overlook OR die)

## EN → UZ remaps (attested / common)

| EN | Prefer |
|---|---|
| early bird | `Erta turganning rizqi koʻp` / `Sahar turgan kishini Xudo oʻnglar` |
| time is money | `Vaqt qimmat` / `Vaqt - bebaho neʼmat` |
| piece of cake | `juda oson` / `xamirdan qil sugʻurgandek` |
| kick the bucket | `vafot etdi` |
| spill the beans | `sirni ochdi` |
| kill two birds with one stone | `Bir oʻq bilan ikki qushni urmoq` |
| bird in the hand… | cultural remap or plain |
| icing on the cake | `Nur ustiga aʼlo nur` |
| no pain, no gain | cultural remap or plain hard-work paraphrase |
| rocket science | `unchalik murakkab ish emas` |

## Attested UZ phrasemes

`tilga olmoq`, `qoʻl urmoq`, `qoʻl qoʻshmoq`, `quloq solmoq`, `koʻzi tushmoq`, `jahli chiqmoq`, `qoʻli ochiq`, `koʻngli keng`, `koʻz yummoq`
