# Particles (yuklamalar)

Light particles make prose human. Overuse makes it fake-chatty.

| Particle | Use | Example |
|---|---|---|
| `-ku` / `axir …-ku` | insistence | `Axir bu mumkin emas-ku` |
| `-chi` | soft prompt / what about | `Sen-chi?` |
| `-mi` | question | `Kelasanmi?` |
| `-u` / `-yu` | emphasis / contrast | `Keldi-yu, darrov ketdi` |
| `-da` | also / emphasis | `Men-da boraman` |
| `-gina` / `-kina` / `-qina` | just / only | `ozgina kutib tur` |
| `faqat` | only | `Faqat bugun` |
| `axir` | after all | `Axir aytgandim` |
| `nahotki` | surely not / surprise | `Nahotki u shunday qildi?` |

## Free spoken glue (voice)

`xoʻp`, `xoʻsh`, `baribir`, `shunchaki`, `endi`, `mana`, `boʻlmasa`, `qani`, `zoʻr`, `yaxshi`, `mayli`

## Rule

Product UI: almost no particles. Assistant chat: light. Youth chat: more OK if requested.
