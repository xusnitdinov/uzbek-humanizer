# Banned calques

Never paste these English "cool" patterns into Uzbek product/student copy.

## Always ban (rewrite)

| Bad (AI / EN) | Prefer |
|---|---|
| ship / ship qilmoq | topshirmoq, chiqarmoq, ishga tushirmoq |
| vibe / vibe check | kayfiyat, tekshirib koʻrmoq |
| portladi | chiqmadi, ishlamadi, ochilmadi |
| teammate | doʻstim, hamkasb, jamoa aʼzosi |
| Systems brain | Tizimni tushunaman / mantiqni tushunaman |
| hard mode | qiyin rejim / murakkab variant |
| feature (as filler) | imkoniyat, funksiya, xususiyat (or name the action) |
| pitch | taklif, taqdimot |
| uplift | yaxshilash, oshirish |
| shadow (UI jargon) | soyali / chuqurroq qatlam - or describe plainly |
| Dream mode | orzular rejimi - usually rewrite to real product language |
| check qilaman (spam) | tekshiraman |
| support qilaman | qoʻllab-quvvatlayman / yordam beraman |
| update qilmoq (when UZ verb exists) | yangilamoq |
| message yozmoq (default) | xabar yozmoq |
| Would you mind… calques | Iltimos, …-ib qoʻying |
| Select the correct answer below | Toʻgʻri javobni belgilang |

## Soft-wrong (grammatical but not native)

| Bad | Prefer |
|---|---|
| Guruh ishi chiqmadi | Guruh ishi oʻxshamadi |
| Loyiha portladi | Loyiha oʻxshamadi |
| qilasan / kirasan (product/quiz) | qilasiz / kirasiz |
| Asabiylashgan doʻstim… (casual) | Stressdagi doʻstim… |

See `soft-synonyms.md` for the full situation bank.

## Allowed sparingly

Wi‑Fi, foto, laptop, gadjet, parol, kod, OTP, PIN, brand names (Payme, Uzum, HUMO).

## Review rule

If the English word is the product name or a globally fixed tech term, keep it. If it is filler swagger, kill it.
