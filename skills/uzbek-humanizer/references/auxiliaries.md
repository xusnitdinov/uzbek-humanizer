# Auxiliaries

Spoken Uzbek often uses converb + auxiliary. AI underuses these and sounds textbook-stiff.

| Form | Feel | Example |
|---|---|---|
| `-ib qoʻymoq` | done / leave as done | `yopib qoʻying` |
| `-ib yubormoq` | sudden / blurt | `aytib yubordi` |
| `-ib qolmoq` | end up / remain | `qolib ketdi` / `tushunib qoldim` |
| `-ib ketmoq` | sudden start / go off | `kulib yubordi` context; `ketib qoldi` |
| `-ib turmoq` / `-ib oʻtirmoq` | ongoing | `kutib turibdi` |
| `-ib boʻlmoq` | completed | `yozib boʻldim` |

## Compound helpers

`qil` / `et` / `boʻl` - prefer a real Uzbek verb when one exists (`tekshiraman` over `check qilaman`).

## UI tip

Soft polite UI: `Iltimos, saqlab qoʻying` beats stiff calques of "Would you mind saving…"
