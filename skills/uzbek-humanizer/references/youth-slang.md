# Youth slang

**Only when asked** for youth / Telegram / peer chat / "doʻstona" slang tone.

Otherwise stick to clean spoken product Uzbek. Do not inject slang to "sound local."

**When slang-heavy, mark:** `draft/native_review_required`

## When to load

- User asks: slang, Telegram vibe, yoshlarcha, peer chat, "karoche" tone
- Not: UI errors, bank/OTP, legal, medical, formal product
