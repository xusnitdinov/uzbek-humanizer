# MT failures

Literal machine-translation / LLM fails → natural Uzbek.

| Source / bad | Good |
|---|---|
| I really like this movie → `Men haqiqatan ham bu filmni yoqtiraman` | `Bu film menga juda yoqadi` |
| kick the bucket → `U chelakni tepdi` | `U vafot etdi` |
| Would you mind closing the door? → stiff calque | `Iltimos, eshikni yopib qoʻying` |
| piece of cake → cake calque | `juda oson` / `xamirdan qil sugʻurgandek` |
| time is money → forced calque in UI | `Vaqt qimmat` / `Vaqt - bebaho neʼmat` |
| I'm not from Uzbekistan → `Men Oʻzbekiston emasman` | `Men Oʻzbekistondan emasman` |
| spill the beans | `sirni ochdi` / plain paraphrase |
| This is not rocket science → `Bu raketa ilmi emas` | `Bu unchalik murakkab ish emas` |
| Togri javob | `Toʻgʻri javob` |
| U oʻqidi kitobni kecha kutubxonada | `U kecha kutubxonada kitobni oʻqidi` |
| Men kitobni doʻstimga berdimga | `Men kitobni doʻstimga berdim` |
| kitoblerimiz | `kitoblarimiz` |
| Hurmatli professor… yaxshisan | `… yaxshisiz` |

## Rule

If an idiom has no sure Uzbek equivalent, paraphrase plainly. Never invent a proverb.
