# Loanword policy

Maqsad “sof” koʻrinish emas. Odamlar ishlatadigan, maʼnosi ravshan soʻzni qoldiring. Soxta adabiy poklik matnni robotdek qiladi.

## KEEP

Quyidagilar odatiy product va kundalik matnda qolsin: **Wi‑Fi, foto, OTP, laptop, brand, cookie, email, PIN, Google, Telegram, Instagram, online, offline, link, chat, QR-kod, video, bonus, promo-kod, profil, test**.

| Soʻz | Tabiiy ishlatish |
|---|---|
| Wi‑Fi | Wi‑Fiʼga ulanib koʻring. |
| OTP | OTP kodini kiriting. |
| email | Emailingizni yozing. |
| PIN | PIN-kodni kiriting. |
| Google | Google orqali kiring. |
| cookie | Cookie sozlamalarini koʻring. |
| laptop | Laptopdan ham ochiladi. |
| brand | Brand haqida qisqacha ayting. |

## KEEP — youth-only

Bular faqat foydalanuvchi aynan yoshlarcha, norasmiy ohang soʻrasa va auditoriya mos bo‘lsa: **story, post, reel, like, follow, DM, podcast, stream, vlog, meme**.

Product/quiz defaultida: `DMʼga yozing` emas, `Xabar yozing`; `like bosing` emas, `Yoqdi deb belgilang` yoki platforma nomi zarur bo‘lsa aynan platforma tilini saqlang.

## REWRITE always

| Avoid | Rewrite | Nega |
|---|---|---|
| ship | juftlik / birga boʻlishini xohlash | EN fandom slengi |
| vibe | kayfiyat / muhit / taassurot | Maʼnosi kontekstga bogʻliq |
| teammate | guruhdoshingiz / jamoadoshingiz | Quizda EN aralashmasin |
| Systems brain | tizimli fikrlash / tartib bilan ishlash | Sunʼiy EN yorliq |
| portladi | juda yoqdi / zoʻr chiqdi | Internet calquesi |
| hard mode | qiyinroq variant / qiyin holat | Oʻyin slengi |
| cringe | noqulay / gʻalati tuyuldi | Registrga moslashtiring |
| random | kutilmagan / tasodifiy | Maʼnoni ajrating |
| literally | rostdan ham / aynan | Koʻpincha ortiqcha |
| mindset | qarash / yondashuv | Oʻzbekcha aniqroq |

## Ambiguous: context decides

| Soʻz | Qoldirish mumkin | Qayta yozish kerak | Misol |
|---|---|---|---|
| app | UI va store kontekstida | umumiy matnda | `Ilovani yangilang`, lekin `app`ni yuklang emas |
| account | login/bank mahsulotida | profil maʼnosida | `Akkauntingizga kiring`; profil rasmi |
| feedback | ish jamoasi kontekstida | oddiy user xabarida | `Fikringizni yozing` |
| deadline | kasbiy chatda | career quizda | `Muddat qisib qolsa` |
| meeting | ish kalendarida | oddiy uchrashuvda | `Uchrashuv qachon?` |
| plan | tarif yoki reja nomida | user niyatida | `Tarif rejasini tanlang`; `Rejangiz nima?` |
| support | bo‘lim nomida | gapda | `Support` nomi qolishi mumkin; `Yordamga yozing` |

**Qoida:** inglizcha soʻz tanishligi uchun emas, aynan shu auditoriya va vaziyatda tabiiy eshitilishi uchun qolsin. Shubhada maʼnoni ochadigan o‘zbekcha variantni tanlang; “elektron pochta xati” singari soxta-literary purity qilmang.
