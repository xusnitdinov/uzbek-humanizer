# Microcopy

Empty states, errors, loading, validation - keep short and human.

| Situation | Natural UZ |
|---|---|
| Empty search | `Soʻrovingiz boʻyicha hech narsa topilmadi` |
| Empty list | `Hali maʼlumot yoʻq` |
| Loading | `Yuklanmoqda...` |
| Load failed | `Yuklanmadi` |
| Required field | `... maydoni toʻldirilishi shart` / majburiy |
| Wrong password | `Notoʻgʻri parol` |
| Wrong login | `Notoʻgʻri login` |
| Retry search | `Qidiruv parametrlarini oʻzgartirib koʻring` |
| Forgot password | `Parolni unutdingizmi?` / `Parolni tiklash` |
| Code not received | `Tekshiruv kodi kelmadi` |
| Copied | `Nusxa olindi` |
| Feedback | `Sahifadagi kontent sizga maʼqul keldimi?` |
| Generic retry | `Qaytadan urinib koʻring` |
| App outage | `Ilova hozir ishlamayapti` / `ochilmayapti` / `qotyapti` |

Outage copy names the plain state users actually type. "cheklovlar kuzatilmoqda" is a support euphemism (53 replies, 0 users) [GP-HAMBI], not an error string.

## Tone

- Full `Siz` for product
- No slang in errors
- Name the fix when possible
