# Soft synonyms (situation-natural)

Calque-free Uzbek can still sound AI if the **verb is wrong for the situation**. Prefer native taste over literal "works / failed / stressed".

Load with `before-after.md` for product / quiz / career copy.

## Failed / didn't work out

| Soft-wrong (AI) | Prefer |
|---|---|
| Guruh ishi **chiqmadi** | Guruh ishi **oʻxshamadi** |
| Loyiha **portladi** | Loyiha **oʻxshamadi** / **muvaffaqiyatsiz tugadi** |
| Reja **chiqmadi** (didn't pan out) | Reja **oʻxshamadi** / **amalga oshmadi** |
| Gap **chiqmadi** (conversation failed) | Suhbat **oʻxshamadi** / **kelisha olmadik** |
| Imtihon **chiqmadi** (didn't go well) | Imtihon **yaxshi oʻtmadi** / **kutilganidek boʻlmadi** |
| Ish **ketmadi** | Ish **oʻxshamadi** / **uddalay olmadim** |

`chiqmadi` is fine for: *kod chiqmadi*, *oyna chiqmadi*, *natija chiqmadi* (literal appear/output).

## Stressed / worried friend

| Soft-wrong | Prefer |
|---|---|
| Asabiylashgan doʻstim holidan xabar olaman | **Stressdagi** doʻstim holidan xabar olaman |
| Nervniy doʻstim | Stressdagi / tashvishdagi doʻstim |
| Depressiyadagi doʻstim (casual quiz) | Kayfiyati tushgan doʻstim (unless clinical + draft) |

## Rule

If a synonym is grammatical but a native would never say it in that quiz/UI line, it is still wrong. Prefer `references/before-after.md` Oria pairs.
