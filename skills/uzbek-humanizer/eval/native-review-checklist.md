# Native review checklist (simulated fallback)

Use this when 3 live native reviewers are unavailable.

## Pass criteria

- [ ] Read aloud test: sounds natural in Toshkent/Fargʻona/Samarqand neutral urban register
- [ ] Context verbs feel right (not one-size-fits-all)
- [ ] Product/quiz lane is consistently `Siz`
- [ ] UI lines are concise (no essay labels)
- [ ] No EN/RU calque rhythm
- [ ] No false formality boilerplate
- [ ] Orthography correct (`ʻ` vs `ʼ`) and EN/RU untouched in mixed files

## Reviewer simulation template

For each sample, score:
- naturalness (1-5)
- context fit (1-5)
- register fidelity (1-5)
- UI brevity (1-5)
- native would say this? (yes/no)

Gate:
- average >= 4.6
- yes-rate >= 95%
