# Register

Default for this skill: **spoken clear product/student** - not presidential stiff, not Telegram slang soup.

| Register | Where | Feel |
|---|---|---|
| Formal / state | gov.uz, lex, decrees | long; `chora-tadbirlar`, `taʼminlash`, `murojaat` |
| News | kun.uz | clear headlines, facts |
| Lifestyle | afisha.uz | human/sensory |
| Tourism | uzbekistan.travel | warm; sometimes translation-y |
| Product / fintech UI | my.gov, Payme | short human - **product default** |
| Ecommerce | Uzum | commerce lexicon |
| Spoken / student | Telegram-clear | `xoʻp`, `chiqmadi`, `doʻstim` - **rewrite default** |
| Youth mix | chat only if asked | slang + RU particles - draft label |

## Matching rule

Match the surface. A bank OTP warning is not a meme caption. A peer chat reply is not a Cabinet resolution.
