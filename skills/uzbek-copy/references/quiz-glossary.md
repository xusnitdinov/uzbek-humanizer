# Quiz glossary

DTM / school / product quiz stems - short, imperative, not English UI paste.

## High-frequency stems

- `Toʻgʻri javobni belgilang`
- `Toʻgʻri javobni toping`
- `Notoʻgʻri jumlani toping`
- `Toʻgʻri jumlani toping`
- `Matnni oʻqing, toʻgʻri javobni belgilang`
- `... toʻgʻri berilgan qatorni belgilang`
- `... mos keladigan toʻgʻri javobni toping`
- `Qaysi qatorda ... berilgan?`
- `... berilgan qatorni toping`
- `Qaysi gapda ... xato mavjud?`
- `Toʻgʻri yozilgan soʻzlar qatorini toping`
- `Qaysi qatordagi soʻzlarda xato bor?`
- `Faqat sinonim soʻzlardan iborat boʻlgan qatorni toping`
- `Chiziqcha (defis) bilan yozish qoidasi buzilgan javobni belgilang`

## Rules

- Prefer `belgilang` / `toping` / `koʻrsating`
- Avoid: `Select the correct answer below…`
- Keep options short; stem carries the task
- Orthography in stems must be correct (`Toʻgʻri` not `Togri`)
