# Voice

## Prefer real verbs

`chiqmadi`, `topshiramiz`, `tushuntiraman`, `soʻrayman`, `qayta tuzaman`, `tekshiraman`

Avoid spam: `check qilaman`, `support qilaman`, `update qilaman` when a Uzbek verb exists.

## Spoken clarity

- Short sentences for UI
- One idea per sentence for product errors
- Concrete over abstract noun stacks
- Light particles only when they help

## Particles / glue

See `particles.md`. Useful: `xoʻp`, `baribir`, `shunchaki`, `endi`, `mayli`.

## Do / Don't

| Do | Don't |
|---|---|
| `Bu imkoniyat chiqmadi` | `Bu feature portladi` |
| `Iltimos, qayta urinib koʻring` | `Please try again later` pasted raw |
| `Doʻstim, topshiramiz` | `Teammate, let's ship` |
