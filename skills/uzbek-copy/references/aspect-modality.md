# Aspect and modality

## Aspect traps

| English feel | Prefer |
|---|---|
| Perfect / completed | `-gan` / `tugatib boʻlgan` / context - not free `-gan` stamp |
| for ten years | `oʻn yildan beri` + present |
| is reading | `-yapti` OK: `U oʻqiyapti` |
| are always complaining | `doim shikoyat qilib yuradi` |
| has been working since | `-dan beri` + `ishlab keladi` / `hali ham` |

## Modality

| Sense | Prefer |
|---|---|
| must / need | `kerak` / `lozim` |
| should have | `kerak edi` |
| can / may | `mumkin` / `-a olmoq` |
| soft request | `-sangiz` / `iltimos` |

## Articles (English a/the)

Uzbek has no articles.
- Default: omit
- Use `bir` / `biror` only when indefiniteness matters
- Use `-ni` for a specific object
- Do not sprinkle `bir` on every noun
